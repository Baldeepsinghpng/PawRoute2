# PawRoute website

A 7-page static site (HTML + CSS + vanilla JS, no build step).

## Pages
index.html, features.html, routes.html, pricing.html, stories.html, about.html, contact.html

## Shared files
- style.css: all design tokens (change colours in `:root`)
- script.js: nav + footer (edit the `pages` array to add pages), particles, animations, route optimiser, calculator

## Publish on GitHub Pages
1. Put all files in the repo root (or replace the old ones).
2. Commit and push.
3. Repo Settings, Pages, Deploy from branch, `main` / root.

## Before going live
Replace placeholder email, prices, persona stories and the illustrative stats on the home page.
Easter egg: try the Konami code.
